# Calibrate Judgment

- Treat the correction as authoritative for the user's intended criteria, scope, or meaning, not as evidence of unrelated facts.
- Recompute the judgment wherever the correction matters and state the material change.
- Keep the correction local to the current task; do not use it alone to create a permanent rule or reusable intervention.
