# Judgment Craft 제품 계약

Judgment Craft는 결과를 크게 바꾸는 선택을 실제 사용자·운영 결과에 연결하고, 반대 증거가 생기면 현재 판단을 즉시 수리하는 Codex 플러그인입니다.

## 제품 약속

- 기술 산출물이나 준비 작업을 제품 가치의 증거로 오인하지 않습니다.
- 중요한 결정을 내리기 전에 실제 결과와 만나는 가장 작은 다음 행동을 고릅니다.
- 이미 타당한 방향은 억지로 바꾸지 않고 `preserve`, `narrow`, `redirect` 중 하나로 분명히 판정합니다.
- 사용자 정정이나 관찰된 반증이 생기면 설명보다 먼저 현재 추천·행동·수용 기준을 수리합니다.
- 한 번의 정정을 사용자 성향이나 영구 규칙으로 일반화하지 않습니다.

## 두 activation 역할

`$judgment-craft`는 비용이 크거나 되돌리기 어려운 약속 전에 방향을 선택하거나 재검증합니다. 제품·사용자 흐름·아키텍처·로드맵·범위·소유권 결정, 영구적인 기술·도구·프로세스 추가, 기술 결과를 제품 이정표로 승격하는 판단에 사용합니다. 승인된 선택의 일상 구현에는 사용하지 않습니다.

`$judgment-repair`는 사용자가 판단의 전제·기준·범위·의미를 정정했거나, 관찰 결과가 이전 판단을 반박했거나, 같은 메커니즘의 실패가 이전 수리 뒤 다시 발생했을 때 사용합니다. 현재 판단과 직접 의존하는 후속 결정만 수리하며, 독립적인 경계에서 멈춥니다.

두 스킬은 순차 절차가 아닙니다. 중요한 선택 전에는 `$judgment-craft`, 반대 증거가 생긴 뒤에는 `$judgment-repair`가 각자 현재 행동을 소유합니다.

## 비목표

- 모든 작업에 적용하는 체크리스트
- 사용자의 성격·취향 프로필 생성
- 모든 선택을 더 작은 선택으로 바꾸는 단순화 규칙
- 정정 한 건에서 규칙·스킬·자동화를 자동 생성하는 학습 시스템
- 분석 문서나 승인 절차를 늘려 판단을 증명하는 체계

## 검증 기준

대표 실패 사례에서 잘못된 약속을 막고, 정상 대조 사례에서는 기존의 좋은 방향을 보존해야 합니다. 사례 재생은 회귀와 반증을 위한 도구이며 일반적 효과의 증명으로 간주하지 않습니다.

## SemVer 의미

Patch는 activation 경계와 행동 계약을 유지하는 호환 가능한 문구·설명·검증·문서 수정입니다.

1.0 이전에는 스킬 추가·삭제, 중요한 trigger 변경, 역할 재편처럼 호환되지 않는 실험적 변경을 다음 minor로 릴리스하고 changelog에 이전 경로를 명시합니다. 1.0 이후 같은 변경은 major입니다.
